# FeiraJá – Projeto Prático em Sistemas (UNINOVE)

Plataforma digital fictícia que conecta feirantes das feiras livres de São Paulo a consumidores do bairro e usa dados e inteligência artificial para reduzir o desperdício de alimentos.

Trabalho da disciplina **Projeto Prático em Sistemas** – Prof.ª Priscilla Viana Cunha – Universidade Nove de Julho, 2026.
